# Travel Agency Monorepo

Modular monolith enterprise travel platform monorepo containing application services and shared packages.

## Workspace Structure

- `apps/backend`: Express & MongoDB Backend Service
- `apps/b2c-web`: B2C Web Client Application
- `apps/b2b-portal`: B2B Partner Portal
- `apps/b2b-admin`: B2B Administrative Dashboard
- `packages/`: Shared workspace packages (`ui`, `types`, `utils`, `config`)
- `docs/`: Architecture Decision Records and API documentation
- `.github/`: CI/CD workflows and repository automation
